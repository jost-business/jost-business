# jost-business Agent Instructions

## Angular Coding Standards

### Control Flow Syntax (MANDATORY)
Use **ONLY Angular 21+ Control Flow Syntax**. Never use legacy structural directives.

✅ **CORRECT:**
```html
@if (condition) {
  <div>content</div>
}

@for (item of items; track item.id) {
  <li>{{ item.name }}</li>
}

@if (user; as currentUser) {
  <p>{{ currentUser.name }}</p>
}

@switch (status) {
  @case ('active') { <span>Active</span> }
  @case ('inactive') { <span>Inactive</span> }
  @default { <span>Unknown</span> }
}
```

❌ **NEVER USE:**
- `*ngIf` → Use `@if` instead
- `*ngFor` → Use `@for` instead
- `*ngSwitch` → Use `@switch` instead
- `*ngTemplateOutlet` → Use `@if (...; as var)` or structural patterns

### Performance Best Practices
- Always use `track` in `@for` loops: `@for (item of items; track item.id)`
- Use `as` for safe navigation: `@if (item; as safeItem)`
- Implement `OnPush` change detection strategy on all components

### TypeScript Standards
- Standalone components only (no NgModules)
- Strong typing - avoid `any` type
- Use type guards and safe navigation patterns
- Getter methods for complex template logic (avoid inline methods)

### Import Organization
- Use workspace aliases: `@jost/shared`, `@jost/models`, etc.
- Group imports: Angular → Third-party → Local

### Styling
- Use centralized theme tokens from `libs/shared/src/styles/`
- CSS custom properties: `--jost-color-*` variants
- Sass for component styles

## Project Structure
- `/apps/` - Standalone applications (shell, finance, about-me, travel, pwa-countdown, playground)
- `/libs/` - Shared libraries (shared, travel/*, ui/*)
- `/certs/` - SSL certificates
- `/db/` - Database schemas and migrations
- `/scripts/` - Utility scripts

## Deployment Standards
- Docker-based deployment with docker-compose
- Nginx reverse proxy configuration
- Environment-aware builds and configs
- Base href should match deployment path
