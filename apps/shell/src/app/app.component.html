Advanced Micro-Frontend Architecture

This is a production-grade micro-frontend application built with Angular 21 and Nx monorepo, demonstrating enterprise-level architecture and DevOps practices.

Key Features

  • Micro-Frontend Architecture: Independent Angular applications (Shell, Finance, About-me, Playground) deployed as separate services
  • Containerized Deployment: Multi-stage Docker builds with optimized production images running on a Virtual Private Server
  • Reverse Proxy & SSL/TLS: Nginx reverse proxy with HTTPS termination and automated SSL certificate management
  • Monorepo Orchestration: Nx for managing dependencies, builds, and cross-app configuration at scale
  • Standalone Components: Modern Angular with zoneless change detection for optimal performance
  • Asset Pipeline: Optimized build output with proper base href routing for sub-applications

Technology Stack

Frontend: Angular 21 (Standalone Components) | Build Tool: Nx 22.5.2 with esbuild | Containerization: Docker & Docker Compose | Reverse Proxy: Nginx with SSL/TLS

Infrastructure

Deployed on a Virtual Private Server (Ubuntu 20.04) with automated container orchestration, monitoring, and production-grade HTTPS. Each micro-frontend runs independently yet seamlessly integrates through intelligent routing and shared navigation patterns.
